# Christmas Shop

![Christmas Shop Interface](./public/images/Screenshot_20260126_235254.png)

A beautiful, interactive Christmas-themed e-commerce website built with vanilla JavaScript, HTML, and SCSS. This project showcases a magical Christmas gift shop where users can browse and discover unique gifts that add superpowers to their lives.

## Features

### Gift Catalog
- **Curated Gift Selection**: Browse a collection of magical Christmas gifts
- **Category Filtering**: Filter gifts by category (For Work, For Health, For Harmony)
- **Random Gift Discovery**: Discover random gifts on the homepage
- **Detailed Modal Views**: Click any gift to view detailed information and superpower effects

### Superpower System
Each gift adds magical superpowers to different aspects of life:
- **Live** (+100 to +500): Enhances vitality and well-being
- **Create** (+100 to +500): Boosts creativity and inspiration
- **Love** (+100 to +500): Strengthens relationships and compassion
- **Dream** (+100 to +500): Fuels imagination and aspirations

### Christmas Countdown
- **Live Countdown Timer**: Real-time countdown to Christmas Day
- **Visual Progress**: Days, hours, minutes, and seconds display
- **Festive Animation**: Countdown updates with smooth transitions

### Interactive Elements
- **Image Slider**: Browse featured gifts with navigation controls
- **Responsive Navigation**: Mobile-friendly burger menu
- **Smooth Scrolling**: Scroll-to-top functionality
- **Modal Popups**: Elegant gift detail overlays

### Responsive Design
- **Mobile-First**: Optimized for all screen sizes
- **Touch-Friendly**: Perfect for mobile and tablet users
- **Progressive Enhancement**: Works across all modern browsers


## 🛠️ Technical Stack

### Frontend Technologies
- **HTML5**: Semantic markup for accessibility and SEO
- **SCSS**: Advanced CSS preprocessing with variables and mixins
- **Vanilla JavaScript ES6+**: Modern JavaScript without frameworks
- **CSS Grid & Flexbox**: Modern layout techniques

### Development Tools
- **ESLint**: Code quality and consistency enforcement
- **Stylelint**: CSS/SCSS style validation
- **Prettier**: Code formatting and consistency
- **NPM**: Package management and build scripts
